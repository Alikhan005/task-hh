# SaleScout — мини прайс-бот

Решение [тестового задания SaleScout](https://github.com/SaleScout-me/salescout-intern-task).
TypeScript, Express, React, Vite и Vitest. Демонстрационный расчёт, без подключения к Kaspi.

## Запуск

Нужен Node.js **20.19+** (или 22.12+) и npm. В `.nvmrc` указан Node.js 20.

```bash
npm install
npm run dev
```

Страница: http://localhost:5173. API: http://localhost:3001/reprice.
Команда запускает сервер и Vite вместе; `Ctrl+C` останавливает оба процесса.

Можно запустить их в двух терминалах:

```bash
npm run dev:server
```

```bash
npm run dev:client
```

При открытии страницы товары из `data/products.json` отправляются в API.
Таблица показывает ответ сервера. Внизу можно изменить JSON и повторить запрос
или вернуть исходный пример. Пустой массив допустим.

## Проверка и сборка

```bash
npm test
npm run typecheck
npm run build
npm start
```

После сборки Express отдаёт и API, и страницу по адресу http://localhost:3001.
Папка `dist` генерируется командой сборки. Для другого порта задайте переменную
окружения `PORT` перед запуском; по умолчанию используется `3001`.

`npm run test:watch` запускает тесты в режиме наблюдения.
Тесты проверяют эталонные данные задания, границы диапазона, округление,
нулевой и дробный шаг, наличие конкурентов, неизменность входного объекта,
а также ответы API на корректные и некорректные запросы.

## API

`POST /reprice`, заголовок `Content-Type: application/json`, тело — массив `Product[]`.

Пример запроса из корня проекта:

```bash
curl -X POST http://localhost:3001/reprice -H "Content-Type: application/json" --data-binary "@data/products.json"
```

В Windows PowerShell при необходимости используйте `curl.exe` вместо `curl`.

Пример тела:

```json
[
  {
    "sku": "PHONE-1",
    "name": "Телефон",
    "myPrice": 180000,
    "minPrice": 150000,
    "maxPrice": 200000,
    "step": 10,
    "competitors": [{ "seller": "Shop", "price": 175000, "inStock": true }]
  }
]
```

Ответ `200`:

```json
[
  {
    "sku": "PHONE-1",
    "oldPrice": 180000,
    "newPrice": 174990,
    "reason": "UNDERCUT"
  }
]
```

Результаты сохраняют порядок товаров. Одинаковые SKU не объединяются.
Названия для таблицы берутся из отправленного массива по индексу.

- `400` и `{ "error": "..." }` — тело не является массивом, неверные поля или JSON.
- `413` и `{ "error": "..." }` — тело запроса больше 1 МБ.
- Пустой массив возвращает `200` и `[]`.

Проверяются обязательные поля, конечные неотрицательные числа, целые границы,
условие `minPrice <= maxPrice` и структура конкурентов. Если один товар
не прошёл проверку, отклоняется весь запрос.

## Как считается цена

`calculatePrice` находится в `src/pricing.ts` и не выполняет I/O.
Проход по конкурентам находит минимальную цену среди тех, у кого `inStock: true`.
`Infinity` используется как начальное значение: по условию все цены конечные,
поэтому оставшаяся `Infinity` означает отсутствие доступных конкурентов.

| Условие                                    | Новая цена | Причина          |
| ------------------------------------------ | ---------- | ---------------- |
| Нет конкурентов в наличии                  | `maxPrice` | `NO_COMPETITORS` |
| `floor(best - step) < minPrice`            | `minPrice` | `AT_MIN`         |
| `floor(best - step) > maxPrice`            | `maxPrice` | `AT_MAX`         |
| Кандидат внутри диапазона, включая границы | Кандидат   | `UNDERCUT`       |

`myPrice` возвращается без изменений как `oldPrice` и не влияет на расчёт.
Валидация находится вне функции, поскольку для неё корректные данные
гарантированы условием задания. Сложность — O(n) по числу конкурентов,
дополнительная память — O(1).

## Файлы

| Путь                | Назначение                                |
| ------------------- | ----------------------------------------- |
| `src/types.ts`      | Типы из шаблона                           |
| `src/pricing.ts`    | Чистая функция расчёта                    |
| `src/validation.ts` | Проверка данных для API и формы           |
| `src/app.ts`        | Express-приложение и обработка ошибок     |
| `src/server.ts`     | Запуск HTTP-сервера                       |
| `web/src/App.tsx`   | Форма, запрос к API и таблица             |
| `tests/`            | Тесты расчёта и HTTP API                  |
| `data/`             | Исходные товары и эталонный ответ задания |

В разработке Vite проксирует `/reprice` на Express, поэтому браузер обращается
к тому же origin. После сборки статику раздаёт сам Express.
